இந்தக் கருவியின் பெயர் கோலத்தின் புள்ளிகளிலிருந்து வந்தது. கோலம் வரைபவர் முதலில் புள்ளிகளை வைத்து, பிறகு அவற்றை இணைக்கிறார். அதுபோலவே, ஒவ்வொரு நூலும் ஒவ்வொரு வாசகரும் ஒரு புள்ளி; அவற்றை இணைப்பதே ஒரு நூலகத்தின் வேலை.

# 点点 — 社区图书馆的开源工具

## 简介

点点是一个虚构的工具，帮助小型社区图书馆轻松管理图书和读者。它为街角的阅览室、学校的傍晚图书角、由志愿者照看的书架而设计。大型图书馆软件对这些地方来说过于复杂；点点提供了一个简单的替代方案。

## 适用人群

- 每周只有几个小时开放图书馆的志愿者。
- 不太熟悉电脑的管理员。
- 网络连接时有时无的乡村阅览室。
- 收藏多种语言图书的学校图书馆。
- 希望有序组织读书会的社区团体。

## 主要功能

1. 图书目录：记录每本书的书名、作者、语言和书架编号。
2. 借阅记录：谁在哪一天借了哪本书，一页就能看清。
3. 还书提醒：在应还日期之前发送一条温和的提醒。
4. 读书会日程：每月读书会的日期、地点和书目，大家都能看到。
5. 离线模式：没有网络时记录照常保存，连网后自动同步。
6. 打印表格：会员卡和月度报告一键即可打印。

## 常见问题

**问：需要付费吗？**
答：不需要。这是一个虚构的开源项目。

**问：读者的信息安全吗？**
答：所有信息只保存在图书馆自己的电脑上，只需要卡号和姓名。
